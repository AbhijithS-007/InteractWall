# 3D Scene JSON Schema

This document defines the schema for the 3D Wallpaper scene files (`scene.json`). This file is generated by the React/Three.js composer UI and consumed by the native D3D11 renderer (`Scene3DViewer.exe` / `Scene3D.dll`).

**File format:** JSON
**Top-level structure:**
```json
{
  "version": 1,
  "name": "My Duck Scene",
  "createdAt": "2026-07-30T10:00:00Z",
  "modifiedAt": "2026-07-30T10:05:00Z",
  "background": {
    "type": "color",
    "value": "#101418"
  },
  "camera": {
    "fov": 45,
    "sensitivity": 0.3,
    "maxRotationOffset": 30.0
  },
  "rendering": {
    "lightingEnabled": false
  },
  "lighting": {
    "ambientColor": "#333333",
    "directionalLights": [
      {
        "color": "#ffffff",
        "direction": [-0.5, -1.0, 0.5],
        "intensity": 1.0
      }
    ]
  },
  "objects": [
    ...
  ]
}
```

## Coordinate System Convention

To ensure perfect 1:1 visual parity between the native D3D11 renderer and the future React/Three.js editor, the scene file STRICTLY adheres to the **Right-Handed, Y-Up** coordinate system (the standard for both glTF and Three.js).

- **+Y**: Up
- **+X**: Right
- **+Z**: Out of the screen (towards the viewer)
- **-Z**: Into the screen (forward)

**Default Camera Setup:**
Unless overridden by future properties, the camera is positioned at `[0, 0, 4]` looking directly towards the origin `[0, 0, 0]` along the -Z axis. The native renderer must translate this standard configuration into its own native matrix format (e.g. mapping RH to LH coordinates if using `XMMatrixLookAtLH`).

**Visible World-Space Bounds:**
Given the fixed camera at `[0, 0, 4]` and a vertical FOV of `45°`, the approximate visible bounds in world space are useful for placement constraints in the editor:
- **At Z = 0** (Distance = 4): Visible height is `[-1.65, 1.65]`. At a 16:9 aspect ratio, visible width is `[-2.94, 2.94]`.
- **At Z = -2** (Distance = 6): Visible height is `[-2.48, 2.48]`. At a 16:9 aspect ratio, visible width is `[-4.41, 4.41]`.

## Top-Level Fields

| Field | Type | Description |
|-------|------|-------------|
| `version` | Integer | Schema version. Currently `1`. Required for future schema migrations. |
| `name` | String | User-facing scene title (e.g. `"My Duck Scene"`), used for library list views. |
| `createdAt` | String | (Optional) ISO timestamp string representing scene creation time. |
| `modifiedAt` | String | (Optional) ISO timestamp string representing last modification time. |
| `background` | Object | Defines the scene backdrop. See [Background Object](#background-object). |
| `camera` | Object | Defines global camera/parallax settings. See [Camera Object](#camera-object). |
| `objects` | Array | A list of 3D objects to render in the scene. See [Scene Object](#scene-object). |

### Background Object
- **`type`**: String. Either `"color"` or `"image"`.
- **`value`**: String. 
  - If `type` is `"color"`, this is a hex color string (e.g., `"#101418"`).
  - If `type` is `"image"`, this is a relative path to the image file (e.g., `"backgrounds/sky.jpg"`). **Paths MUST be relative to the JSON scene file's containing folder.**
- **`fit`**: String. (Optional, used only when type is `"image"`, default `"cover"`). Defines how the image fills the screen:
  - `"cover"`: Crop image to fill the entire screen while maintaining aspect ratio.
  - `"contain"`: Letterbox the image to fit the screen entirely without cropping.
  - `"stretch"`: Fill the screen exactly, distorting aspect ratio if necessary.
  - `"tile"`: Repeat the image at its native resolution.

## Camera (`camera`)
* `fov`: Float, vertical field of view in degrees.
* `sensitivity`: Float, how strongly the camera rotates based on cursor movement.
* `maxRotationOffset`: Float, maximum cursor-driven rotation offset in degrees.

## Rendering (`rendering`)
* `lightingEnabled`: Boolean (default `false`). When false, uses an extremely cheap, unlit shader pass for maximum performance on low-end integrated graphics (the original Phase 1/2 look). When true, enables the Lambert diffuse and Blinn-Phong specular lighting pass defined in the `lighting` block. This ensures that new scenes have minimal performance overhead by default.

## Lighting (`lighting`)
* `ambientColor`: Hex string (e.g., `"#333333"`), representing the base ambient light applied globally to the scene to prevent completely black shadows. Defaults to `"#333333"`.
* `directionalLights`: Array of directional light objects (up to 4 supported by the renderer).
  * `color`: Hex string for the light color.
  * `direction`: Array of 3 floats `[x, y, z]` representing the direction the light is pointing *towards* in the world. (e.g. `[-0.5, -1.0, 0.5]` points down, left, and forwards).
  * `intensity`: Float, brightness multiplier for this light.

## Objects (`objects`)

### Scene Object
Each entry in the `objects` array represents a 3D model placed in the scene.

| Field | Type | Description |
|-------|------|-------------|
| `id` | String | A stable, unique identifier (e.g., `"obj_1a2b3c"`). This ID never changes once assigned, allowing the editor UI to track and reference specific objects across edits and array reorders. |
| `model` | String | Relative path to the `.glb` model file (e.g., `"models/duck.glb"`). **Paths MUST be relative to the JSON scene file's containing folder.** Assets are stored locally within the scene's directory to ensure portability. |
| `position` | Array[Float, 3] | `[x, y, z]` position in world space. |
| `rotation` | Array[Float, 3] | `[x, y, z]` **Base/Resting Rotation** in degrees, applying Euler angles in **XYZ order**. When `followMouse` is true, cursor-driven parallax rotation is ADDED on top of this base pose. Toggling it off returns the object to this exact resting orientation. |
| `scale` | Array[Float, 3] | `[x, y, z]` scale multipliers (default `[1.0, 1.0, 1.0]`). |
| `followMouse` | Boolean | If `true`, the object dynamically rotates in response to cursor movement. If `false`, the object ignores cursor offsets and remains strictly at its base `rotation`. |
| `rotationMultiplier` | Float | (Optional, default `1.0`). Scales how strongly this specific object reacts to cursor movement relative to the global `camera.sensitivity`. |
